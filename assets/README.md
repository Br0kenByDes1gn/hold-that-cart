# Hold That Cart: Individual Product PNGs\n\nContains 106 individually cropped transparent PNG assets from the generated product sheet. Each file is named for its depicted item and padded so the main object is not clipped. Assets are centered on a 256×256 transparent canvas.\n\nNote: some generated icons depict grouped products (for example, a fruit assortment or vegetable assortment). Names are descriptive estimates based on the source image.\n
